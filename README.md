# I95: Safety Run landing page

A one-page website for the mobile game I95: Safety Run (`com.pkartintel.i95`).

- `index.html` is the page; `privacy.html` is the privacy policy; `img/` holds the artwork and screenshots.
- It is plain HTML and CSS with nothing to build. It is published with GitHub Pages from the `gh-pages` branch of https://github.com/PKDoughnut/I95-Policy-and-Landing
- When the game is live on Google Play, switch the "Coming soon" button for the link that is in a comment beside it in `index.html`.
